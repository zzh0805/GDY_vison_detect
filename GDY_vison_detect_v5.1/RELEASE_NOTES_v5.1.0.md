# v5.1.0 更新说明

日期：2026-09-22。基于本地 `GDY_vison_detect_v5` 独立创建，未修改原目录。

## 新增

- 独立C++相机进程：原生SDK生命周期、软件触发、清缓存、配对取帧、连续RGB和模式切换均在C++执行。
- 同一HTTP端口 `/preview/start`、`/preview/stop`、`/preview/status`、`/preview/rgb.mjpg`。
- `field_test/14_record_rgb_preview.py`：通过服务录制MP4，打印SDK采集/接收fps并保存统计JSON，不控制机器人。
- `workflow.yaml`集中配置曝光、增益、匹配参数、超时、内存上限、预览发布和录制参数。
- C++帧RAII、固定容量共享内存、单最新帧缓存、串行IPC复制、慢客户端上限、异常退出和双开防护。
- 彩深时间戳诊断：无效/不递增/原始时差超过阈值支持warn或strict，默认warn兼容已有流程。

## 保持不变

原快照、识别、TCP接口、MinIO交付、快照缓存语义和field_test的触发拍照行为。
YOLO、几何配准、点云重建、手眼/工具偏移、机器人运动算法、模型及标定数据。
当前默认不强行设置曝光或SDK匹配参数；需在现场验证范围和读回后启用。

## 验证结果

- Python离线回归：116项通过，包括模拟HTTP到MP4录制及解码。
- C++假SDK状态测试：100次预览/拍照切换、1000张预览帧，及清缓存失败、异常帧、超时、无效时间戳和参数设置失败。
  所有帧对象离开操作后计数归零，最高同时持有2个SDK帧对象，相机/系统指针在关闭后释放。
- C++生产代码：用提供的CHM提取的SDK头文件，通过Linux ARM64与x86_64目标文件编译。
- 未连接真实相机；未与部署设备的实际SDK动态库链接、未测真实fps/切换延迟/长时间RSS。

假SDK测试只证明本项目相关路径的状态与所有权，不证明厂商SDK内部无泄漏；没有宣称硬件曝光同步。

部署步骤、参数说明、改动范围和现场验收清单见 `V5_1_PREVIEW.md`。
